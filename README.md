# Contact Management System with Admin Dashboard

A responsive front-end contact management system that allows users to submit messages and enables an admin to view, manage, and delete submissions through a dedicated dashboard.

Built using **HTML, CSS, and JavaScript**, this project demonstrates client-side validation, data persistence using localStorage, and dynamic DOM manipulation.

---

## Features

- User contact form with validation
- Data stored using browser localStorage
- Admin dashboard to view submitted messages
- Delete functionality for message management
- Responsive modern UI design
- Dynamic message rendering

---

## Technologies Used

- HTML5
- CSS3 (Flexbox, modern layout styling)
- JavaScript (DOM manipulation, localStorage, events)

---

## What This Project Demonstrates

- Front-end system logic
- Data handling using arrays and objects
- Persistent browser storage
- Dynamic UI updates
- Basic admin system structure
